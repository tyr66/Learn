计算流程

- 根据一个方向向量, 计算出需要进行采样的面.
- 根据该方向向量，计算出在对应面的uv坐标。
- 在该面对应的二维的纹理上使用该uv坐标进行采样.

hlsl代码如下所示

```hlsl
float2 sampleCube(
    const float3 v,
    out float faceIndex)
{
	float3 vAbs = abs(v);
	float ma;
	float2 uv;
	if(vAbs.z >= vAbs.x && vAbs.z >= vAbs.y)
	{
		faceIndex = v.z < 0.0 ? 5.0 : 4.0;
		ma = 0.5 / vAbs.z;
		uv = float2(v.z < 0.0 ? -v.x : v.x, -v.y);
	}
	else if(vAbs.y >= vAbs.x)
	{
		faceIndex = v.y < 0.0 ? 3.0 : 2.0;
		ma = 0.5 / vAbs.y;
		uv = float2(v.x, v.y < 0.0 ? -v.z : v.z);
	}
	else
	{
		faceIndex = v.x < 0.0 ? 1.0 : 0.0;
		ma = 0.5 / vAbs.x;
		uv = float2(v.x < 0.0 ? v.z : -v.z, -v.y);
	}
	return uv * ma + 0.5;
}
```
注意点
- 方向向量并不一定需要归一化, 通过因为我们只需要该向量方向信息，而不需要向量的长度信息。想象一下透视投影中将点从视锥体映射到投影平面上的过程。
- 判断向量在哪个面上只需要判断向量分量的绝对值哪一个最大即可, 因为如何将该向量和该分量对应的轴(例如 (0, 1, 0) 或者是 (0,0,1))进行点乘的话绝对值越大那么该向量和该轴的夹角就越小。那么该向量就越靠近该轴对应的面
