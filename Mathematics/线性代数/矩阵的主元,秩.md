# 矩阵的主元

定义：

**矩阵的主元为矩阵进行消元后每行中第一个非零元素。**

# 矩阵的秩(Rank)

秩的三种定义：

1. **矩阵的秩为矩阵主元的数量**
2. **矩阵中的最大的线性无关的行向量和列向量数量**
3. **矩阵的行空间和列空间的维度**

$mxn$矩阵中主元的个数被称为矩阵的秩(rank)，记作$r$
$$
r<= m \\
r<= n
$$

# 为什么矩阵的 row rank 等于 column rank

证明：

对于矩阵$A$我们将其进行消元得到简化行阶梯矩阵$rref(A) = R$，矩阵$A$和矩阵$R$互为行等价矩阵.因此两个矩阵的行空间是相同的，并且虽然列空间可能不同但是，两个矩阵的列向量的独立性是互相对应的。因此有

$$
row \ rank(A) = row \ rank(R) \\
column \ rank(A) = column \ rank(R)
$$

对于矩阵$R$来说, 它的row rank和column rank都等于主元的数量

$$
row \ rank(R) = number \ of\ pivot \\
column \ rank(R) = number \ of\ pivot
$$

因此有

$$
row\ rank(A) = column\ rank(A)
$$

补充：

- 矩阵$R$的 row rank 等于其中非零行的数量(此时非零行为行空间的基). 而矩阵$R$中每一个非零行都有一个主元。
- 矩阵$R$的column rank 等于pivot的数量是因为，简化行阶梯矩阵$R$中主元对应的列向量都是标准单位向量, 它们为列空间的基
